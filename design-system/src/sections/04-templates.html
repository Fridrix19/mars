Подключение в Nuxt

// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['@primevue/nuxt-module'],
  css: ['~/assets/base.css', '~/assets/lib.css', '~/assets/pv-bridge.css'],
  primevue: {
    options: {
      ripple: false,
      theme: { preset: Marscap, options: { darkModeSelector: '.mc-dark', cssLayer: false } }
    }
  },
  app: { head: { htmlAttrs: { 'data-mc-theme': 'dark', class: 'mc-dark' } } }
})

// composables/useTheme.ts — переключатель в шапке
export const useTheme = () => {
  const theme = useState('mc-theme', () => 'dark')
  const apply = (t) => {
    document.documentElement.dataset.mcTheme = t
    document.documentElement.classList.toggle('mc-dark', t !== 'light')
    localStorage.setItem('mc-theme', t)
  }
  return { theme, toggle: () => apply(theme.value = theme.value === 'light' ? 'dark' : 'light') }
}
Порядок CSSbase.css (токены, база) → lib.css (компоненты) → тема PrimeVue → pv-bridge.css (мост). Мост всегда последний, без cssLayer, чтобы побеждать по специфичности.
Тема до отрисовкиИнлайн-скрипт в <head> читает localStorage('mc-theme') и ставит атрибут и класс до первого кадра — без вспышки.
ГалактикаКлиентский компонент <GalaxyBg client-only /> с galaxy-bg.v58.js; на страницах кабинета, входа и документов не подключается.
ИконкиСвой набор SVG-компонентов (штрих 1,7); PrimeIcons не подключаются, чтобы не смешивать два стиля.
КаталогJSON из assets/services и category-icons собирается на этапе сборки; яркость логотипа считается там же и даёт флаг on-dark.

Текст и контент

Интерфейс говорит коротко, по делу и на «вы». Он объясняет, что произойдёт, называет сроки и суммы точно и не обещает того, чего не контролирует.

ТонСпокойный и конкретный. Без восклицательных знаков, без «Упс», без «мы рады». Юмор не используется — речь о деньгах.
Обращение«Вы» со строчной. Не «пользователь», не «клиент» — в интерфейсе нет третьего лица.
ЗаголовкиИменное или глагольное, до 6 слов, без точки: «Два шага до карты», «Что будет после оплаты».
КнопкиГлагол в инфинитиве + результат: «Оплатить 2 407 ₽», «Выпустить карту», «Написать в поддержку».
Кикеры1–3 слова, без дефиса и точки: «Расчёт и оформление», «Шаг 01».
ЧислаТысячи через неразрывный пробел, десятичные через запятую в рублях и курсе (80,2254 ₽), через точку в долларах ($7.99). Знак валюты после числа для ₽, перед — для $.
СрокиКонкретно: «до 15 минут», «в течение часа», не «скоро» и не «в ближайшее время».
Названия сервисовКак у самого сервиса: ChatGPT Plus, Cursor AI, Midjourney. Планы — как на сайте сервиса, без перевода: Pro, Teams, Standard.
ОшибкиЧто случилось + как исправить, рядом с местом. См. раздел 14.
Пустые состоянияЧто здесь бывает + один следующий шаг. См. раздел 16.
ЮридическоеОдна строка под кнопкой оплаты: «Нажимая «Оплатить», вы принимаете условия оферты» со ссылкой. Не чекбокс.

Доступность

Цель — WCAG 2.2 AA. Список ниже проверяется на каждой странице перед публикацией; большинство пунктов уже встроено в компоненты, но их легко сломать при сборке.

КонтрастТекст ≥ 4,5:1, крупный текст и элементы управления ≥ 3:1 в обеих темах. --text-4 не используется на плитках.
КлавиатураВсё интерактивное — <button>, <a href>, <input>. Порядок табуляции совпадает с визуальным. Фокус видим: кольцо 2px --focus.
ИменаИконочные кнопки — aria-label. Поля — <label for>. Поиск — aria-label. Логотипы в плитках — alt="", имя сервиса в тексте рядом.
СостоянияВыбранное — aria-pressed / aria-selected / aria-current; ошибка — aria-invalid + aria-describedby; загрузка — aria-busy; переключатель — role="switch".
Живые областиИтог расчёта и статус — aria-live="polite"; тосты — role="status", ошибки — role="alert"; область создаётся заранее.
ДиалогиФокус внутрь и обратно, Esc закрывает, фон инертен (inert), заголовок связан через aria-labelledby.
ДвижениеВсё внутри prefers-reduced-motion: no-preference; карта, орбиты и галактика останавливаются, скелеты и спиннеры замирают.
Зона касания≥ 44px у всех целей на тач; малые кнопки 38 добираются отступами.
МасштабСтраница работает при 200% и ширине 320px без горизонтального скролла; шрифт полей 16px.
ЗаголовкиОдин h1 на страницу, уровни без пропусков, секции — <section> с заголовком, навигация — <nav aria-label>.
ЦветСтатус всегда дублируется точкой, иконкой или текстом; ошибка поля — рамка и текст.
Язык<html lang="ru">; названия сервисов и планов на латинице без lang-переключения.
