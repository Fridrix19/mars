# Marscap · Дизайн-система

Документация интерфейса store.marscap.ru: токены, типографика, сетка, компоненты с превью в светлой и тёмной теме, шаблоны страниц и соответствие компонентам PrimeVue 4 для Nuxt.

**Открыть:** `index.html` — самодостаточный документ, работает офлайн (шрифты подгружаются с Google Fonts).

## Состав

| Путь | Что это |
|---|---|
| `index.html` | Собранный документ (v1.0) |
| `src/base.css` | Токены обеих тем и базовые компоненты сайта — источник значений для документа |
| `src/lib.css` | Библиотека компонентов: формы, навигация, карточки, оверлеи |
| `src/pv-preset.js` | Пресет PrimeVue (`definePreset(Aura, MARSCAP_PRESET)`) из тех же токенов |
| `src/ds.css`, `src/ds.js` | Оболочка документа: навигация, превью, переключатель темы, кнопка «Код» |
| `src/sections/*.html` | Разделы документа по порядку: 00 введение · 01–06 основы · 07–17 компоненты · 18–20 шаблоны · 21–23 реализация |

## Разделы

Введение — принципы. Основы — цвета, типографика, сетка и отступы, радиусы/тени/слои, движение, иконки и логотипы. Компоненты — кнопки, поля ввода, выбор, навигация, карточки, таблицы и ведомости, статусы, сообщения и диалоги, загрузки, пустые состояния, аккордеон и списки. Шаблоны — структура страницы, готовые блоки, карта страниц. Реализация — PrimeVue и Nuxt, текст и контент, доступность.

## Правила

- Источник правды — токены в `base.css`; если документ и код разошлись, прав код.
- Компоненты используют только роли (`--accent`, `--surface`), не примитивы.
- Иконки категорий и логотипы сервисов не редактируются.
- Всё движение — внутри `prefers-reduced-motion: no-preference`.
